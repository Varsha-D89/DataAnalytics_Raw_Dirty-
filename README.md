# Manufacturing Analytics Dashboards using Power BI
## Project Objective
The objective of this project is to develop interactive Power BI dashboards for analyzing manufacturing operations. The project focuses on monitoring production trends, evaluating machine performance, measuring equipment effectiveness (OEE), analyzing shift productivity, tracking defect rates, assessing energy efficiency, and identifying maintenance requirements. These insights help improve operational efficiency, product quality, resource utilization, and decision-making in manufacturing environments.

## Questions(XPIs)
- 1.What is the production trend over time?
- 2.Which machine is the most productive?
- 3.Which machine has the highest downtime?
- 4.Is higher downtime affecting production?
- 5.What is the equipment availability rate?
- 6.Is product quality within acceptable limits?
- 7.Which shift is the most productive?
- 8.Which shift consumes the most energy?
- 9.Which machine has the highest defect rate?
- 10.Which machines are most energy efficient?
- 11.Is there a relationship between energy consumption and production output?
- 12.Which machines show signs of potential maintenance issues?

## Process
- 1.Data Collection:
- Gather manufacturing production data from machines and shifts.
- Include production units, downtime, defects, energy consumption, temperature, and operating hours.
- 2.Data Cleaning & Preparation:
- Remove missing values and duplicates.
- Format data types and validate records.
- 3.Data Import:
- Import the dataset into Power BI.
- 4.Data Modeling:
- Establish relationships between tables (if applicable).
- Create calculated measures using DAX.
- 5.Dashboard Development:
- Production Trend Dashboard
- Machine Performance Dashboard
- OEE Dashboard
- Shift Analysis Dashboard
- Defect Rate Dashboard
- Energy Efficiency Dashboard
- Predictive Maintenance Dashboard
- 6.Data Analysis:
- Analyze production performance, downtime, quality, and energy usage.
- Identify trends, inefficiencies, and maintenance requirements.
- 7.Visualization & Reporting:
- Create interactive charts, KPI cards, and reports.
- Present insights for data-driven decision-making.
- 8.Conclusion:
- Evaluate manufacturing efficiency and provide actionable recommendations for improving productivity, quality, and operational performance.

## Project Insights
- Production showed a generally stable trend with a slight upward growth over the observed period, indicating consistent manufacturing performance.
- Machine M2 was the most productive machine, while M3 had the lowest production output and requires performance improvement.
- Equipment availability reached 97%, indicating minimal downtime and strong operational reliability.
- Quality performance was excellent with a 99% quality rate, showing very low defect levels.
- Shift A achieved the highest production output, demonstrating better resource utilization compared to other shifts.
- Machine M3 recorded the highest defect rate, highlighting the need for maintenance and process optimization.
- Energy consumption increased with production output, though efficiency varied across machines. Machines M1 and M4 showed better energy efficiency.
- Rising temperature and downtime trends can serve as early indicators of potential machine failures, supporting predictive maintenance planning.

## Conclusion
- This project successfully developed a comprehensive set of Power BI dashboards for manufacturing analytics.
