# Manufacturing Analytics Dashboards using Power BI
## Project Objective
The objective of this project is to develop interactive Power BI dashboards for analyzing manufacturing operations. The project focuses on monitoring production trends, evaluating machine performance, measuring equipment effectiveness (OEE), analyzing shift productivity, tracking defect rates, assessing energy efficiency, and identifying maintenance requirements. These insights help improve operational efficiency, product quality, resource utilization, and decision-making in manufacturing environments.

## Questions(XPIs)
What is the production trend over time?
Which machine is the most productive?
Which machine has the highest downtime?
Is higher downtime affecting production?
What is the equipment availability rate?
Is product quality within acceptable limits?
Which shift is the most productive?
Which shift consumes the most energy?
Which machine has the highest defect rate?
Which machines are most energy efficient?
Is there a relationship between energy consumption and production output?
Which machines show signs of potential maintenance issues?

## Process
Data Collection
Gather manufacturing production data from machines and shifts.
Include production units, downtime, defects, energy consumption, temperature, and operating hours.
Data Cleaning & Preparation
Remove missing values and duplicates.
Format data types and validate records.
Data Import
Import the dataset into Power BI.
Data Modeling
Establish relationships between tables (if applicable).
Create calculated measures using DAX.
Dashboard Development

Machine Performance Dashboard

Defect Rate Dashboard
Energy Efficiency Dashboard
Predictive Maintenance Dashboard
Data Analysis
Analyze production performance, downtime, quality, and energy usage.
Identify trends, inefficiencies, and maintenance requirements.
Visualization & Reporting
Create interactive charts, KPI cards, and reports.
Present insights for data-driven decision-making.
Conclusion
Evaluate manufacturing efficiency and provide actionable recommendations for improving productivity, quality, and operational performance.
